# Security Policy

## Supported versions

Security fixes are applied to the latest `main` branch and the latest published release when practical.

## Reporting a vulnerability

Please report security issues privately through GitHub's private vulnerability reporting for this repository, if enabled. Do not open a public issue containing credentials, session files, phone numbers, personal data, or an exploit that affects real Telegram accounts.

When reporting, include the affected version, impact, reproduction steps, and a safe proof of concept. Never send API credentials or active session files.
